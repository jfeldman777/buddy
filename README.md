# Buddy

**Опыт трудных побед**

Би — ваш ИИ-партнёр. Он помогает справляться с трудностями, находить решения и приобретать собственный опыт побед.

Сайт: https://jfeldman777.github.io/buddy/

Статус: Alpha 0.01 в разработке. Готовы этапы 1–3 — стартовая страница, PWA, знакомство с Би без ИИ (выбор голоса, имя, узнавание при следующем запуске) и журнал поступков Би на устройстве: объяснение Би, действия программы, проверка по декларациям D1–D7, оценка пользователя, экспорт и удаление. Голосовой ввод — по кнопке 🎤 и только с разрешения пользователя. Этап 4 — сервер (Cloudflare Worker + D1): учётные записи по passkey и коду восстановления, роль администратора, защита API; сервер готов к развёртыванию, на сайте подключается после него.

## Структура

- `web/` — статический сайт (PWA), публикуется на GitHub Pages
- `server/` — API: Cloudflare Worker + D1 (`src/`, `migrations/`, `test/`, `wrangler.toml`)
- `tests/` — автоматические проверки
- `tools/` — генераторы значков и QR-кода, локальный сервер
- `docs/` — документы проекта

## Разработка

Нужен Node.js 24 или новее (тесты сервера используют встроенный `node:sqlite` вместо D1).

```
npm install
npm run serve   # http://localhost:8080/buddy/
npm test
```

Сервер локально: `server/.dev.vars.example` → `server/.dev.vars`, затем `npm run api:migrate:local` и `npm run api:dev` (http://localhost:8787). Развёртывание — в [архитектуре](docs/architecture.md#сервер-этапа-4-как-устроен-и-как-развернуть).

После изменения файлов сайта выполните `npm run bump`: номер версии (например, 003 → 004) обновится в `web/version.json`, `web/sw.js` и на страницах. Открытые копии Buddy увидят новый номер и предложат кнопку «Обновить»; без этого установленные приложения без сети покажут старую версию.

Значки: `powershell -ExecutionPolicy Bypass -File tools/make-icons.ps1` (Windows). QR-код: `npm run qr`.

## Безопасность

Репозиторий публичный. Ключи API, личные данные, разговоры, журналы и финансовые записи в него не попадают. Каждый push проверяется на секреты (gitleaks) и тестами.
