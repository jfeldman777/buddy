# Buddy

**Опыт трудных побед**

Би — ваш ИИ-партнёр. Он помогает справляться с трудностями, находить решения и приобретать собственный опыт побед.

Сайт: https://jfeldman777.github.io/buddy/

Статус: Alpha 0.01 в разработке. Готов этап 1 — стартовая страница и PWA.

## Документы

- [Техзадание 001](docs/spec-001.md)
- [Архитектура и утверждённый план](docs/architecture.md) — решения, принятые при согласовании; при расхождении с техзаданием действуют они
- [Концепция Buddy](docs/concept.md)
- [Декларации Би](web/declarations.json) — D1–D7; поле `check` показывает, как проверяется соблюдение: `program` — программой по зарегистрированным действиям, `review` — по объяснению Би и оценке пользователя

## Структура

- `web/` — статический сайт (PWA), публикуется на GitHub Pages
- `tests/` — автоматические проверки
- `tools/` — генераторы значков и QR-кода, локальный сервер
- `docs/` — документы проекта

## Разработка

Нужен Node.js 20 или новее.

```
npm install
npm run serve   # http://localhost:8080/buddy/
npm test
```

После изменения файлов сайта увеличьте `CACHE_VERSION` в `web/sw.js`, иначе установленные копии приложения покажут старую версию без сети.

Значки: `powershell -ExecutionPolicy Bypass -File tools/make-icons.ps1` (Windows). QR-код: `npm run qr`.

## Безопасность

Репозиторий публичный. Ключи API, личные данные, разговоры, журналы и финансовые записи в него не попадают. Каждый push проверяется на секреты (gitleaks) и тестами.
