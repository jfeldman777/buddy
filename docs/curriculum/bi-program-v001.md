## 3. Логика последовательности

1. **Фактический порядок Notion:** 1 → 13 (как в каталоге).  
2. **Учебный порядок v001:** совпадает с фактическим, потому что автор явно задаёт наращивание: метафора инженера → классы вопросов → отсечения → поле внимания → шкалы → пространство состояний → потребности задач → четыре грани → разбор граней → иллюстрация (музыка).  
3. **Порции автора:** «порциями по пять глав, после порции — тест». Учебные вехи проверки (ещё не экзаменатор): после F05 (конец стр. 1–5) и после F13/F14 (конец корпуса).  
4. Отличие учебного порядка от Notion в v001 **не вводилось**; при появлении противоречий между страницами Методист отметит их в §4, а не «склеит».

## 4. Пробелы, повторения, противоречия

### Пробелы чтения

- Не выдумывать недостающие абзацы.

### Повторения (осознанные, не сливать)
- «Точки» Бахуса / Аполлона / Наполеона / Архимеда (стр. 3) ↔ шкала в таблице стр. 5.  
- Уровни 1–8 в музыке (стр. 13) ↔ уровни поля внимания / грани.  
- «Задача предъявляет требования — человек отвечает способностью» (стр. 7–8) будет ядром применения.

### Противоречия
- В v001 содержательных противоречий между **прочитанными** фрагментами не зафиксировано.  
- Возможные уточнения терминов «со-знание» vs «сознание» (стр. 10–11) — держать раздельно до проверки контекста API.

### Технические сбои
