## 4. Пробелы, повторения, противоречия

### Пробелы чтения
Нет по API. В Markdown остаются заголовки-заглушки следующей `child_page` (например в конце стр. 5 — «# 6.Глава вторая» без тела) — это указатель, не потеря блоков.

### Повторения (не сливать)
- Точки Бахуса/Аполлона/Наполеона/Архимеда (стр. 3) ↔ колонка отсечений (стр. 5).  
- Лестница возрастов (стр. 5) ↔ музыка 1–8 (стр. 13) ↔ таблицы мышления/взаимодействия.  
- «Опыт трудных побед» (стр. 5) — явный мост к слогану Buddy; не смешивать с бытовым «победил в споре».

### Противоречия
- «Со-знание» (автор) vs «сознание» когнитивистов — на стр. 10 явно разведены; держать раздельно.  
- Ответ на стр. 11 на вопрос об уровне теоретического сознания в снятом тексте краткий («Со-знание») + таблица типов — при обучении сверять с намерением автора, не додумывать номер уровня без источника.
