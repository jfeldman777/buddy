# DCB-010 — согласованные решения

Тренировочный модуль Ди–Си–Би. При расхождении с черновиком плана действует этот документ и явное разрешение разработчика от 2026-10-16.

## Решения

- Настоящий OpenAI API; общий бюджет первоначальных испытаний **$10** (10_000_000 микродолларов), жёсткий потолок на сервере (`CHECK` + резервы). Превышение запрещено.
- Модель задаётся переменной Worker `OPENAI_MODEL` (по умолчанию `gpt-6-luna` — дешёвая актуальная модель под бюджет $10). Альтернативы: `gpt-6.1-sol` (дороже). Если доступа нет — Project → Limits / Model access или сменить `OPENAI_MODEL`.
- Первый Ди — администратор (elevated-сессия). Приглашения других Ди — позже.
- Режимы: **малый** и **большой**; переход малый→большой с сохранением истории. Обратный переход не делается.
- Интерфейс: `web/dcb.html`.
- Протоколы DCB хранятся в D1 в таблицах `dcb_*`, отдельно от личных диалогов Buddy (те по-прежнему только на устройстве).
- Язык сеанса — русский.
- Си раскрывает биографию постепенно. В большом режиме новые факты пишутся в `dcb_persona_memory` и не должны противоречить ранее установленным.
- Скрытое описание Си программно недоступно Би: раздельные сборщики промптов и автотесты изоляции с маркером.
- После сеанса Ди вводит оценки, замечания и идеи.
- Публикация — только с отдельного разрешения разработчика.

## Изоляция

- `buildSiPrompt` получает `secret_bio` и память Си.
- `buildBiPrompt` получает только диалог и модель Би (+ режим). Поле `secret_bio` в код пути Би не передаётся.
- Автотест: в запросе OpenAI для хода Би нет `SECRET_MARKER_…` из скрытой биографии; для хода Си — есть.

## Версия стратегии Би

`dcb-bi-facts-v1` — первый слой: факты биографии, люди и связи.
