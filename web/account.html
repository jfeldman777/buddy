Вход

Вход нужен тем, у кого уже есть учётная запись Buddy. Знакомство с Би, голос и журнал работают без входа.

На сервер попадают только данные для входа: открытая часть ключа passkey и отпечаток кода восстановления. Имя, разговоры с Би и журнал остаются на этом устройстве и на сервер не отправляются.

Учётные записи заработают, когда подключат сервер Buddy. Всё остальное работает и без них.

Ваш код восстановления

Сохраните код сейчас: запишите на бумаге или сохраните в менеджере паролей. Код показывается один раз. На сервере хранится только его отпечаток, по которому сам код узнать нельзя.

Код нужен, если passkey пропадёт, например при смене телефона. Каждый код срабатывает один раз: после входа по коду вы получите новый.

Войти можно отпечатком пальца, лицом или PIN-кодом телефона — это passkey. Пароль не нужен.

Этот браузер не поддерживает passkey. Войти можно по коду восстановления.

Учётная запись появится, когда вы оформите доступ к разговору с Би. Если её ещё нет, входить пока не нужно.

Новая учётная запись

Passkey сохранится на этом устройстве, а вы получите код восстановления на случай потери телефона.

Нет passkey на этом устройстве?

Можно создать учётную запись только с кодом восстановления. Тогда код — единственный ключ: если потерять его, войти будет нельзя. Добавьте passkey, как только появится возможность.

При входе по коду и создании учётной записи Cloudflare Turnstile проверяет, что это человек, а не программа.
